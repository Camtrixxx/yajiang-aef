# 实验记录：v1.2 A800 8 卡训练与评测

## 1. 实验目标

本轮实验把雅江 AEF 训练主线从华为 Ascend/NPU 环境迁移到 NVIDIA A800 CUDA 环境，并在 8 卡上完成 v1.2 模型训练、续训和评测。

核心目标不是只提升重建指标，而是训练一个雅江地区多模态 embedding，使其后续可以冻结 encoder 并接少量简单任务头完成下游任务。

## 2. 环境

## 4. 关键工程改动

### CUDA/A800 适配

- 训练脚本默认使用 `CUDA_VISIBLE_DEVICES` 和 `torchrun`。
- 支持通过 `GPU_IDS` / `CUDA_VISIBLE_DEVICES` / `NPROC_PER_NODE` 指定 GPU。
- 启用 bf16 AMP、TF32、cuDNN benchmark。
- DDP 默认 `find_unused_parameters: false`。

### DataLoader 加速

```yaml
data:
  batch_size: 4
  num_workers: 8
  persistent_workers: true
  prefetch_factor: 4
  drop_last: true
```

### 训练续跑

`scripts/train_with_manifest.py` 新增：

```text
--resume
--resume-no-optimizer
```

`Trainer.load_checkpoint()` 支持恢复 model / optimizer / scaler / epoch / global_step / best_loss，并可用当前 config 覆盖 optimizer lr。

### 数据与损失优化

- Dataset 支持按 source 配置 resize / crop_pad / normalization。
- target 统一 resize 到 decoder 输出大小。
- categorical loss 支持 class weights。
- target loss 支持 per-target weights。
- all-ignore categorical target 返回 graph-preserving zero loss。
- `sensor_encoders.py` 修复 bf16 AMP 下 dtype mismatch。
- `time_encoder` 在 `use_time_codes: false` 时冻结。

## 10. 重建指标对比

| 版本 | DEM MAE | DEM R2 | WorldCover macro F1 | WorldCover macro IoU |
| --- | ---: | ---: | ---: | ---: |
| 50 epoch | 0.1086 | 0.9750 | 0.5736 | 0.4387 |
| 100 epoch | 0.0829 | 0.9845 | 0.6917 | 0.5533 |
| 200 epoch | 0.0712 | 0.9889 | 0.7837 | 0.6596 |

结论：训练越久，decoder 重建越好。200 epoch 是当前重建最佳版本。

## 11. 下游 few-shot 对比

WorldCover few-shot AEF macro F1：

| 版本 | 1-shot | 5-shot | 10-shot | 50-shot |
| --- | ---: | ---: | ---: | ---: |
| 50 epoch | 0.2031 | 0.3216 | 0.3345 | 0.3267 |
| 100 epoch | 0.1535 | 0.2284 | 0.2711 | 0.3065 |
| 200 epoch | 0.1146 | 0.1494 | 0.2191 | 0.2700 |

DEM few-shot AEF R2：

| 版本 | 1-shot | 5-shot | 10-shot | 50-shot |
| --- | ---: | ---: | ---: | ---: |
| 50 epoch | 0.4182 | 0.3551 | 0.3370 | 0.6592 |
| 100 epoch | 0.1956 | 0.2524 | 0.1906 | 0.6337 |
| 200 epoch | 0.1118 | 0.2314 | 0.0561 | 0.5013 |

结论：few-shot embedding 表现随着续训下降。50 epoch 是当前最适合作为通用 embedding 的版本。

## 12. 当前判断

如果应用目标是：

```text
预训练雅江地区多模态 embedding
冻结 encoder
接简单任务头
少量标注即可得到不错效果
```

那么 checkpoint 选择应以 downstream probe 为主：

```text
优先选择 v1.2 50 epoch
```

如果应用目标是：

```text
重建 / 补全 / 解码生成 DEM、WorldCover 或 JRC Water
```

则：

```text
优先选择 v1.2_continue_200
```

## 13. 后续优化方向

当前现象说明模型继续训练后越来越服务于 decoder 重建目标，但 embedding 的线性可分性和小样本迁移能力下降。下一步建议：

1. 引入以 embedding 为中心的验证指标，按 few-shot probe 选择 best checkpoint。
2. 对 decoder 和 encoder 训练做解耦，例如降低 decoder loss 权重、加入 projector、或阶段性冻结 decoder。
3. 加强对比学习 / masked prediction / cross-modal alignment，让 embedding 直接承担表征学习压力。
4. 使用更接近真实应用的下游任务头 benchmark，而不仅是现有 WorldCover / DEM / JRC probe。
5. 建立独立 eval manifest，避免长期只在训练 manifest 上做诊断。
